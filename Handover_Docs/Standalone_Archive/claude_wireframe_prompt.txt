================================================================================
1. CORE ARCHITECTURAL REQUIREMENTS & CONSTRAINTS
================================================================================

1.1 Standalone System Boundary
- The QuickBox Financial Management System is a strictly standalone financial platform.
- It has ZERO dependencies on inventory, warehouse stock, physical SKUs, linen/hospitality rooms, supply logistics, or hotel reservation models.
- All entities, calculations, tables, and workflows represent pure financial accounting constructs: General Ledger, Chart of Accounts, Double-Entry Journal Vouchers, Invoices (AR), Bills & Expenses (AP), Payroll & WPS Tax Withholdings, VAT / Regulatory Compliance, Fixed Asset Depreciation Schedules, Bank Statement Feeds & 2-Way Reconciliation, and Formal IFRS/GAAP Financial Statements.

1.2 Technical Stack Specification
- Framework: React 19 (Functional Components, React Hooks: `useState`, `useMemo`, `useCallback`, `useReducer`, `useRef`, `useEffect`).
- Styling: Tailwind CSS utility classes paired with custom CSS custom properties (design tokens) for pixel-perfect density, crisp 1px borders, and elevated card aesthetics.
- Iconography: Lucide React (or Phosphor Icons React) icons across navigation, action buttons, table menus, metric cards, and status badges.
- Charts & Visualizations: Custom inline responsive SVG charts (smooth continuous area curves, dual-axis bar charts, donut distribution graphs, horizontal aging bars) with interactive node hover states, tooltips, and legends.
- Interactivity & State Management: In-memory stateful React implementation with instant view switching, dynamic multi-tier filtering, real-time search, interactive modal dialogs, slide-over drawers, expandable sub-tables (accordions), live debit/credit balancing validation, and floating alert toast notifications.
- Language: 100% English across all UI labels, code, mock data, and tooltips.

1.3 Global Design Tokens & Theme Variables
The UI must implement a clean, light-mode financial theme with high information density, subtle borders, and distinct semantic status colors:
- Background Canvas: `#f3f4f6` (Cool Grey 100)
- Surface Background (Main Cards/Tables): `#ffffff` (Pure White)
- Sidebar Background: `#f8faf9` (Soft Mint / Light Grey)
- Primary Brand Accent: `#5eb160` (Emerald Accounting Green) / Hover: `#4e9e50`
- Primary Brand Navy: `#0f172a` (Deep Slate / Navy 900)
- Border Subtle: `#e5e7eb` (Cool Grey 200) / Border Highlight: `#d1d5db`
- Typography:
  - Base UI Font: Inter / system-ui, -apple-system, sans-serif (11px to 14px for high density)
  - Monospace Data Font: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace (used for Account Codes, Voucher IDs, Invoice Numbers, Currency Amounts, and Dates)
- Semantic Status Colors:
  - Success (Paid / Balanced / Reconciled / Active): Background `#dcfce7`, Text `#16a34a`, Dot `#22c55e`
  - Warning (Pending / Scheduled / Draft / Due Soon): Background `#fef9c3`, Text `#ca8a04`, Dot `#eab308`
  - Danger (Overdue / Unbalanced / High Discrepancy): Background `#fee2e2`, Text `#dc2626`, Dot `#ef4444`
  - Info (Processing / Capitalized / Non-Operating): Background `#e0e7ff`, Text `#4f46e5`, Dot `#6366f1`
